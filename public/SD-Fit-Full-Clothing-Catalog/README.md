# SD Fit Full Clothing Catalog

This archive contains separate image files for the clothing and style categories represented in the SD Fit overview.

## Categories
- Boys: T-shirts, shirts, hoodies/sweatshirts, jackets, jeans, trousers/chinos, shorts, ethnic wear, footwear, accessories.
- Girls: tops, shirts/blouses, kurtis/ethnic tops, dresses, jeans, trousers/pants, shorts/skirts, ethnic bottoms/dupatta, outerwear, innerwear, footwear, accessories.

## Website integration
- `catalog.json` is the structured catalog with audience, category, item ID, display name and relative image path.
- `catalog.csv` is a spreadsheet-friendly version.
- Images are organized in category folders for easy use in the frontend.

## Important
These are generated illustrative catalogue tiles cropped from a single generated catalog sheet. Some crops may include a little adjacent whitespace or label. They are not individual transparent cutouts or verified retail product photos. For accurate final outfit previews, replace or supplement them with isolated transparent PNG/WebP garment assets photographed from the front, and record each actual product's size chart, fabric stretch, color, and fit. Clothing sizes differ by brand and product.
